WINDMESH

Wildfire Spread Prediction Model inputting Live Data

DEMO
OVERVIEW

Sudden changes in wind speed and direction make wildfires spread in erratic, hard-to-predict ways. WindMesh gives firefighters a simulation that follows the wind as it changes, built on the Rothermel surface fire spread model behind fire management systems worldwide.

Our team of four built it at LexHack ’26 with no hackathon experience, and it took 2nd place.

THE GOAL

Predict fire spread accurately on a satellite map using nodes, even in chaotic weather, with real wind data from one theoretical node changing how the fire spreads.

WHAT I BUILT
  • Led the 4-person team.
  • Designed the hardware: a DIY anemometer to measure the wind.
  • Wrote the Python that feeds live anemometer data into the simulation.
  • Made the summary video and trained the team for the presentation.
THE CHALLENGE

This was my first time designing something technical from scratch, working out each piece by intuition, and with limited resources to build it from.

I had barely used Python before. I learned to use Claude to fill the gaps in my code while making sure every part still followed exactly the logic I had planned.
