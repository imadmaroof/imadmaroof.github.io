AIRFRAME AE

Real-time impact detection for aircraft panels, using acoustic emission.

DEMO
OVERVIEW

Airplanes are only checked for structural damage on the ground, every 100 to 1,000 flight hours. In between, small cracks that look harmless can quickly spread into major damage that is far more expensive and time-consuming to repair. Airframe AE catches them early.

It uses acoustic emission: the stress waves a structure gives off when it is struck or starts to crack. The system isolates the frequencies those waves produce, so not every little noise is read as a crack, then compares the signal across the sensor array to locate the impact and flag it on a live aircraft diagram, highlighting high-risk zones such as wing roots and door frames.

THE GOAL

Have the microphones detect a tap that is neither too hard nor too soft, using frequency isolation, and show it live on the simulation.

WHAT I BUILT
  • Wired the piezoelectric microphones to the Arduino Uno Q.
  • Wrote the Python link between the sensor array and the visualization.
  • Worked on the localization software that triangulates each impact.
THE CHALLENGE

I had to learn how the electronics worked, and how to wire them properly, under time pressure, so everything could be assembled correctly as soon as the parts arrived.

SKILLS LEARNT
  • Hands-on electronics: wiring sensors to a microcontroller
  • Building with Claude Code
TECH STACK

  • Arduino Uno Q
  • MAX4466 piezo mics
  • Acoustic emission
