# Imad Aboo — Portfolio

My personal portfolio, live at **[imadmaroof.github.io](https://imadmaroof.github.io)**.

It's built like a Super Mario World map. You walk a pixel version of me (straw
hat, suit) along the path, and each pipe is one of my projects. Stand on a pipe
to see a quick preview, then jump in to open the full project page. The castle
at the end is how to get in touch.

## Getting around

- **Arrow keys** or **click** to walk between projects
- **Enter** to go down a pipe
- **LIST VIEW** in the top bar shows every project on one plain page, no game
- **RESUME** in the top bar opens my resume
- On a phone, the map turns into a simple scrollable list

Greyed-out **?** blocks are projects I haven't published yet.

## Built with

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. No frameworks and no
build step. All the pixel art, including me, is drawn in code.
