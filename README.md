# Imad Aboo's Portfolio

My personal portfolio, live at **[imadmaroof.github.io](https://imadmaroof.github.io)**.

It's built like a Super Mario World map. You walk a pixel version of me (straw
hat, suit) along the path, and each pipe is one of my projects. Stand on a pipe
to see a quick preview, then jump in to open the full project page. Between the
pipes are **?** blocks: hit one and it opens a chest of the skills I picked up
along the way (CAD, soldering, 3D printing, coding, electronics and so on). The
castle at the end is how to get in touch.

## Getting around

When you arrive you pick a mode: **ADVENTURE** (the map) or **LIST VIEW**
(every project on one plain page, no game). You can switch any time from the
top bar.

- **Left / right arrows** or **click** to walk along the path
- **Up** under a **?** block to jump and hit it
- **Enter** to go down a pipe
- **LIST VIEW** in the top bar switches to the plain list
- **RESUME** in the top bar opens my resume
- On a phone, the map turns into a simple scrollable list

Grey **?** blocks standing in for a pipe are projects I haven't published yet.

## Built with

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. No frameworks and no
build step. All the pixel art, including me, is drawn in code.
